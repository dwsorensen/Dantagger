Bits on the wire

Everything the FPGA and the PC say to each other comes in 4096-byte frames. Streamed events are 64-bit records, or, in release 3's compact runs, 32-bit words. Type any value below and see it decoded field by field, or edit a field and see the bits change.

All values are little-endian. Words are numbered from the start of the frame: word 0 is bytes 0–3.

The 64-bit record

One event, or one marker

Bit 63 says which. An event is one GPX2 result: channel, the low 16 bits of the FPGA's coarse time, the reference index and the stop result. A marker carries the full 48-bit coarse time and marks the start or end of a run, a clock tick, or dropped events. Records are what the decoder, the raw recordings and tdcctl files all use. Compact runs are expanded back into them on arrival.

Why only 16 coarse bits in an event? A TIME marker with the full 48 bits comes whenever the low 14 bits wrap, every 131 µs, and no record is more than 8 cycles older than the one before it. So consecutive records are never more than 2¹⁵ ticks apart, and the host unwraps the 16 bits as a signed difference from the last record it saw.
Decoder (RecordDecoder::feed): diff = int16(coarse_low − (coarse & 0xFFFF)); coarse += diff. Then t_cand = (ref × divisions + stop) × lsb. An event with stop ≥ divisions (125 000) is counted as corrupt and skipped. An OVERFLOW marker becomes three Swabian tags: OverflowBegin at the watermark, then MissedEvents (with the count) and OverflowEnd at the marker's time.
Release 3 compact words

Half the size, same information

In a compact run each event is one 32-bit word: an 18-bit stop result, the channel, and the low 12 bits of the reference index. The upper 12 index bits change slowly, so they travel in an occasional EPOCH word. Markers become three words. Words whose top six bits are all ones are reserved for everything that is not an event.

An event carries no coarse time at all. The host gives it the coarse time of the last marker, which can be up to one TIME period (131 µs) early. The decoder allows for that in its wrap budget and its watermark margin. With a 24-bit index (2.1 s per lap) this costs nothing.

Rules (PROTOCOL.md 3.4): an EPOCH word comes before an event whenever bits 23:12 of its index differ from the last EPOCH of the run (always before the run's first event), and only then. The EPOCH and its event are in the same frame. A marker's three words are always in one frame. A frame payload is always 1007 words, with PAD (0xFFFFFFFF) after the last record. The host-side code is tdcctl::CompactExpander. CompactPacker is the FPGA's packer in software, checked word for word against 33 compact frames from the RTL simulation.
The frame

4096 bytes, word by word

Every frame in both directions has the same envelope: a 16-word header, 1007 payload words, and a CRC. Each square below is one 32-bit word. Hover or tap one.

The FPGA silently drops (and counts in field 4) any COMMAND frame with a bad magic, version or type, a length other than 4096, a nonzero offset, seed, flags or timestamp word, a byte-enable other than 1111 on any word, a CRC error, or a partial frame left idle for 10 ms. Only one command may be outstanding, and every accepted frame gets exactly one RESPONSE. A DATA frame is built when 503 records (compact: 1007 words) are waiting, when records have waited 1 ms, or at once while a run ends.

Commands

Header word 10 is the opcode, word 12 the payload length in bytes, and the payload starts at word 16. Every payload word past the valid length must be zero.

StatusMeaning

5 DEVICE_ERRORit ran, but a device NACKed, a readback did not match, or a bus timed out
6 NOT_READYSTART: GPX2 not measuring with a verified configuration, LCLKIN off, clocks not locked, or (compact) the format does not allow compact records

When several apply, the first in this order wins: BAD_COMMAND, BAD_ARGUMENT, BUSY, NOT_READY, DEVICE_ERROR.

GPX_CONFIGURE board rules

The FPGA refuses the command (BAD_ARGUMENT, nothing sent to the chip) unless:

  • register 0 bit 4 PIN_ENA_REFCLK = 1 (REFCLK comes from the LMK1D1204);
  • register 1: HIGH_RESOLUTION ≠ 3, CHANNEL_COMBINE ≠ 3;
  • registers 3–5: 1 ≤ REFCLK_DIVISIONS ≤ 2^stop_bits − 1;
  • register 7 bit 7 REFCLK_BY_XOSC = 0;
  • the fixed bits: register 5 bits 7:4 = 0, register 6 bits 7:5 = 110 and 3:0 = 0, register 7 bit 6 = 1 and 3:0 = 0011, registers 8–15 = A1 13 00 0A CC CC F1 7D, register 16 = 0.

Then: power the chip's logic off and on (0x30), write (0x80), read back and compare all 17 bytes, INIT (0x18) only if they match, and read back again.
